# Abacus Studio for Claude Code

Install the plugin, connect to Studio, and set up your application. Then describe
what you want to change.

- **Submit** saves your progress to the shared sandbox repository. It does not
  make changes live.
- **Request publish** asks Abacus to review your submitted changes for release.
  It does not automatically publish them.

Follow the [step-by-step installation and usage guide](INSTALL.md).
